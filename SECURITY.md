# Security Policy

This tool structures a procurement review from a vendor-supplied record; it reads a file and
returns a verdict, with no network or execution of input. It is decision *support* — the human
sign-off is still required. A rule that produces a false GO is the high-severity failure mode.

Report issues **in this tool** privately: GitHub **Report a vulnerability** on this repo, or email
the contact on the org profile. Target: **5 business days** to acknowledge, coordinated disclosure.
